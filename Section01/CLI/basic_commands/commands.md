- pwd
  показывает полный путь к текущей папке, в которой вы находитесь

- ls 
  показывает список файлов и папок в текущей директории

- ls -l 
  показывает подробный список: права доступа, владельца, размер, дату изменения и имя файла

- ls -a 
  показывает все файлы, включая скрытые (их имена начинаются с точки: .bashrc, .gitignore)

- ls -la 
  комбинация -l и -a. Показывает подробную информацию обо всех файлах, включая скрытые

- cat file_name 
  читает и выводит содержимое файла в терминал

- cd directory_path 
  переходит в указанную папку

- cd ../.. 
  Переход на два уровня вверх по дереву папок

- vim file_name 
  Открывает файл в текстовом редакторе Vim (установлен почти на всех Linux-системах)

- echo abc 
  Выводит текст в терминал. В данном случае выведет abc
